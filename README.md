## 🚀 Featured Projects

</div>

<details>
<summary><b>🧠 Cortex — Production Retrieval-Augmented Intelligence Platform</b></summary>
<br/>

> An enterprise-grade RAG platform that turns internal corpora into a queryable, auditable knowledge fabric with full evaluation, re-ranking, and grounding guarantees.

<br/>

| **Aspect** | **Detail** |
| :--- | :--- |
| **Stack** | Python, FastAPI, LangChain, pgvector, Redis, Next.js, TypeScript, Kubernetes, Terraform |
| **Scale** | 12M+ documents indexed · 4k QPS sustained · multi-tenant |
| **Performance** | p95 retrieval latency 180 ms · end-to-end answer latency 1.4 s |
| **Security** | Row-level tenancy, KMS encryption, SSO/SAML, full audit trail |
| **Impact** | Replaced a legacy knowledge base and cut average research time by 62% across 8 product teams |
| **Repository** | `github.com/Yahiro025/cortex-rag` |

<br/>

Cortex was built around a single thesis: **enterprise knowledge is only valuable if it's trustworthy, fast, and observable.** The platform ships a hybrid retrieval pipeline (BM25 + dense + cross-encoder re-ranking), per-tenant vector namespaces, and a continuous evaluation harness that scores drift, grounding, and answer quality against a held-out gold set. Fronted by a strict typed React/Next.js application with role-based workspace views and a shareable, citation-rich answer component that product teams can embed directly into internal tools.

</details>

<details>
<summary><b>⚡ Hydra — Distributed Model Training & Inference Fabric</b></summary>
<br/>

> A cloud-native ML platform that schedules multi-node training jobs and serves low-latency inference at production scale, with autoscaling, canary rollouts, and cost-aware scheduling.

<br/>

| **Aspect** | **Detail** |
| :--- | :--- |
| **Stack** | PyTorch, Ray, Kubernetes, Triton Inference Server, gRPC, Postgres, Prometheus, Grafana |
| **Scale** | 200+ concurrent training jobs · 1.2B-parameter models served across 3 regions |
| **Performance** | Inference p99 38 ms · 3.8× cost reduction vs. always-on GPU pools |
| **Security** | Sandboxed tenants, mTLS service mesh, signed model artifacts, SBOM per release |
| **Impact** | Standardized ML delivery for 14 internal teams and cut model-to-prod cycle by 71% |
| **Repository** | `github.com/Yahiro025/hydra-ml` |

<br/>

Hydra was an exercise in **applying systems engineering to ML workloads**. The scheduler bins-packs GPU workloads by topology, warehouses, and SLAs, and treats model artifacts as immutable, signed, versioned artifacts that graduate from shadow traffic to canary to full production with automatic rollback on regression. The serving tier exploits dynamic batching, paged attention, and speculative decoding for LLM inference, and exposes a single typed SDK so product engineers never have to think about the underlying cluster.

</details>

<details>
<summary><b>🛰️ Sentinel — Real-Time Streaming Anomaly Detection System</b></summary>
<br/>

> An end-to-end streaming anomaly detection platform combining classical ML, deep sequence models, and rule engines with a feedback loop from operator actions.

<br/>

| **Aspect** | **Detail** |
| :--- | :--- |
| **Stack** | Kafka, Flink, Python, scikit-learn, PyTorch, TimescaleDB, Grafana, React |
| **Scale** | 220k events/sec · 9-month production uptime, zero data loss |
| **Performance** | Detection latency 850 ms p99 · 5× fewer false positives vs. baseline |
| **Security** | PII tokenization, encrypted rest + transit, GDPR-compliant data retention |
| **Impact** | Prevented an estimated $4.3M/yr in fraud and SLA-breach incidents |
| **Repository** | `github.com/Yahiro025/sentinel-anomaly` |

<br/>

Sentinel was my deep dive into **streaming-first ML systems**. Events are scored by a tiered ensemble — fast rules for known signatures, gradient-boosted trees for medium-fidelity scoring, and an LSTM-Transformer hybrid for rare-but-high-impact sequences. Alerts flow to a triage UI where analyst feedback is captured as a labeled stream and continuously retrains the ensemble via a champion-challenger loop.

</details>
